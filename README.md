## Contenido

En este repositorio se encuentran los cuadernos desarrollados durante el taller, organizados de acuerdo con los temas trabajados:

* `01-Python-Cadenas.ipynb`
* `02-Python-Tuplas.ipynb`
* `03-Python-Listas.ipynb`
* `04-Python-Conjuntos.ipynb`

* `06-Python-Condiciones.ipynb`
* `07-Python-Bucles.ipynb`
* `08-Python-Funciones.ipynb`

## Descripción

En cada cuaderno se desarrollan los ejercicios propuestos, incluyendo una breve explicación de las actividades realizadas, el código implementado y los resultados obtenidos.

También se incluyen conclusiones al final de los cuadernos como complemento al desarrollo del taller.
